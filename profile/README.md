# Northflow Technologies AS

We build and run products and platforms in Europe, and our research reads the planet from orbit.

[northflow.no](https://northflow.no) · [Northflow Space and Research](https://research.northflow.no) · [Northflow Business](https://business.northflow.no)

Northflow Technologies AS is a technology company in Stavanger, Norway. We publish the code of our research tools here.

## Open projects

| Project | What it does | Licence |
|---------|--------------|---------|
| [CERES](https://github.com/northflowlabs/ceres) | The public website and dashboard of CERES, weekly forecasts of acute food insecurity in 43 countries | Apache 2.0 (code), CC BY 4.0 (forecasts) |
| [LITHOS](https://github.com/northflowlabs/lithos) | A ground motion map of how the ground rises and sinks, from radar satellite data | Apache 2.0 |
| [PSE](https://github.com/northflowlabs/pse) | Fuses Earth observation and environmental data into one queryable API | Apache 2.0 |
| [climval](https://github.com/northflowlabs/climval) | Validates and benchmarks climate model output against reference data | Apache 2.0 |
| [northflow-notebooks](https://github.com/northflowlabs/northflow-notebooks) | Reproducible climate validation notebooks built on climval | Apache 2.0 |
| [mission-data-pipeline](https://github.com/northflowlabs/mission-data-pipeline) | A typed Python ETL framework for CCSDS spacecraft telemetry | MIT |
